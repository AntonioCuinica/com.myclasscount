MyClassCount
Manual de Utilizador
Neste manual encontrara dicas importantes de como utilizador de forma eficiente o programa MyClassCout para uma melhor experiencia e gestão da sua explicação.

1.Login
Apos instalar o programa, use as credencias abaixo para fazer entrar no sistema:
Username	Senha
admin	admin


2. Tela inicial
Apos fazer o login, o usuário será redirecionado para tela inicial, onde terá um menu com lista de função a executar no sistema. Os menus de cima permitem visualizar dados cadastrados e os de baixo na parte central permitem cadastrar novos dados, tais como alunos, professores, turmas e novas disciplinas.
 

3. Cadastrar alunos
Esta tela é responsável por inserir novos, estudantes no sistema, sendo necessários preencher alguns campos de forma obrigatória e indicar uma categoria na qual o estudante pertence, de modo a estabelecer o valor pago por cada disciplina inscrita do estudante em questão.
 
3.1 Ver e modificar dados dos alunos
Esta janela permite ver dados dos estudantes, permitindo modificar os mesmos, clicando duas vezes sobre o estudante e por sua vez permite inscrever um estudante numa disciplina, permitindo assim que haja contagem das mensalidades.
 

4.Cadastrar professor
Esta tela permite inserir novos professores, os professores possuem uma conta usuário, ou seja, são responsáveis por usar o sistema. Estes possuem dois papeis diferentes admin e normal, o admin tem total controle do sistema enquanto que o normal tem acesso limitado.
 
5.Ver professores
Tela responsável por mostrar todos professores cadastrados e permitir modificar os seus dados. Para modificar os dados de um professor é necessário dar dois cliques no campo referente ao mesmo, após isso será aberta uma janela que permitir ver dados com mais detalhes e modifica-los se necessário.
 


5.1 Atualizar dados de professores
Ao clicar duas vezes num professor, na lista de professores, será aberto uma janela que permite visualizar com mais detalhes os dados dos professores e modifica-los, bem como remover a conta do professor caso necessário.
 
6. Categorias 
Área responsável pela criação de novas categorias, modificação de categorias existentes. Uma categoria define o valor que cada estudante deve pagar por disciplina ao ser inscrito nessa mesma categoria, sendo que cada categoria é definida para uma classe ou nível especifico. 
 


7. Criar Turmas
As turmas agrupam um conjunto de alunos que pertencem a mesma classe e que frequentam o mesmo horário. Sendo possível criar varias turmas de classes diferentes. Ao criar uma turma pode definir um horário num único dia da semana, caso haja necessidade de definir mais dias pode-se aceder ao campo de visualizar turma, modifica-la de modo a aumentar mais dias.
 

 






7.1. Ver e modificar turmas
Neste campo é possível ver a turma criada, todos alunos adicionados, bem como modificar e eliminar a turma criada. Ao clicar duas vezes no campo de um estudante, aparecera uma janela que permite, adicionar uma observação e remover o aluno selecionado.
 

 





8. Ver mensalidades
Nessa janela é possível ver todas mensalidades dos estudantes, marcar as mensalidades pagas bem como verificar as dividas dos estudantes.
